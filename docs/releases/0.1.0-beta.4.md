# 책먹는 몬스터 0.1.0-beta.4

네 번째 Windows 공개 베타입니다. 베타 테스트에서 확인된 서재 피드백 부족, 데이터 관리
용어의 모호함, 정적인 펫 동작과 작은 화면에서의 잘림을 중심으로 개선했습니다.

## 이번 버전의 변경 사항

- 독서기록이 없는 추천은 베스트셀러 순서라는 콜드스타트 안내 추가
- 추천의 `읽고 싶음`과 서재의 모든 상태 변경에 결과·의미 안내창 추가
- 서재 책 제목·저자 수정과 안전 삭제 추가. 삭제해도 독서 문장과 이미 형성된 유전·성장은 보존
- 새 책 등록에서 ISBN·서명·저자명 조회, 판본 선택, 직접 입력 fallback 제공
- `기록 읽기`가 현재 책·기록·유전·성장·도감·친밀도를 백업 후 교체한다는 경고 강화
- `전체 초기화`가 앱 설정과 Windows 자동 실행까지 기본 상태로 되돌리도록 변경
- `내 몬스터 정보 보기`, `읽은 범위`, `시작 시 애니메이션 실행` 등 모호한 용어 정리
- 친밀도에 따라 말하는 빈도와 시작 인사말이 달라지고, 대사의 결은 독서 유전 혈통을 유지
- 바닥 중심 이동, 화면 끝의 `콩!`, 드래그 후 낙하 모션 추가
- 간식·맛있는 표정·놀기·씻기 동작을 서로 구분
- 몬스터 크기 100%·75%·50% 설정 추가
- `집에 보내기 (트레이 축소)`와 트레이 복귀/종료 추가
- 서재·기록·추천·책 조회 화면에 필요한 스크롤 추가
- 종료 시 최종 확인창 추가

## 데이터와 진화 원칙

친밀도는 몬스터가 말하는 빈도와 인사 태도에 영향을 주지만 독서기록으로 정해지는 진화
혈통을 바꾸지 않습니다. 서재에서 책을 삭제해도 독서 문장과 유전정보는 남고, 모든 기록과
성장 상태를 지우는 작업은 이중 확인이 있는 `전체 초기화`에서만 수행됩니다.

기록 읽기와 전체 초기화 직전에는 현재 독서기록·몬스터 상태를 자동 백업합니다. 업데이트와
제거는 `%LOCALAPPDATA%\BookEater`의 사용자 데이터를 삭제하지 않습니다.

## 베타에서 알고 있어야 할 점

- 아직 Authenticode 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
- 최종 진화 12종의 확정 이름과 개별 원화는 이후 안전하게 교체할 수 있도록 분리되어 있습니다.
- 다중 모니터별 작업영역 처리는 추가 검증이 필요합니다.
