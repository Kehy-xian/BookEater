# 책먹는 몬스터 0.1.0-beta.1

첫 Windows 공개 베타입니다. 독서 기록과 분석은 기본적으로 이 PC 안에만 저장되고,
업데이트·재설치·제거 과정에서도 사용자 DB, 설정과 백업은 삭제하지 않습니다.

## 포함된 기능

- 책을 한 번 등록한 뒤 시간순으로 독서 기록을 계속 추가
- 작성 중 초안 자동 저장·복원과 저장 우선 분석
- 번들 E5 모델을 이용한 로컬·오프라인 다중라벨 분석
- 성장, 이동, 대화, 기억, 도감, 돌봄과 미니게임
- 기록 내보내기·심기·안전한 초기화
- 중복된 책 제목·저자도 정확한 책을 선택하는 충돌 방지
- 사용자 확인 후 HTTPS 다운로드, SHA-256 검증과 Windows 인스톨러 실행

## 설치와 업데이트

`BookEater-Setup.exe`를 실행하면 사용자 계정 아래에 설치됩니다. 이전 테스트 빌드 위에
설치해도 `%LOCALAPPDATA%\BookEater`의 기록, 설정과 백업은 유지됩니다. 앱 안에서는
설정의 업데이트 확인 버튼을 눌러 새 버전을 직접 확인할 수 있습니다.

## 베타에서 알고 있어야 할 점

- 아직 Authenticode 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
- 온라인 도서 검색의 공개 카탈로그 서버는 아직 연결되지 않아 수동 등록으로 동작합니다.
- 분석 개선용 데이터 제공은 구현·활성화되지 않았으며 기본 로컬 처리만 사용합니다.
- 일부 성장 형태는 최종 아트가 아닌 검증용 번들 아트를 사용합니다.

문제가 생겨도 기존 독서 기록을 덮어쓰지 말고, 데이터 폴더와 백업을 보존한 상태로
재현 절차를 함께 알려 주세요.
