# 책먹는 몬스터 0.1.0-beta.3

세 번째 Windows 공개 베타입니다. 실제 알라딘 도서 검색을 Cloudflare Worker를 통해
연결했습니다. 이용자는 별도 계정이나 API 키를 입력할 필요가 없습니다.

## 이번 버전의 변경 사항

- 실제 알라딘 도서 목록을 이용한 추천 후보 연결
- 알라딘 TTB 키를 Windows 앱에 포함하지 않고 Cloudflare Worker secret으로 보호
- 명시적 검색어 또는 일반 베스트셀러 목록만 서버로 전송하고 독서 기록·성향·진화
  이력은 전송하지 않음
- Worker의 `items` 응답과 기존 개발 프록시의 `books` 응답을 모두 안전하게 처리
- ISBN/ISBN13을 실제 도서 식별자로 사용하고 알라딘 상세 링크의 HTML 엔티티를 복원
- 카탈로그 HTTPS 최종 URL, 응답 크기와 `Content-Length` 검증 강화
- Release 전에 실제 운영 카탈로그에서 도서를 받아 앱 형식으로 변환하는 smoke 검사 추가

## 설치와 데이터 보존

기존 설치 위에 실행하면 프로그램 파일만 갱신합니다. `%LOCALAPPDATA%\BookEater`의 독서
기록 DB, 설정, 백업, 교정값과 성장 이력은 덮어쓰거나 삭제하지 않습니다. 서버 장애나
알라딘 할당량 초과 시에도 로컬 기록과 수동 도서 등록은 계속 사용할 수 있습니다.

## 베타에서 알고 있어야 할 점

- 아직 Authenticode 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
- 분석 개선용 데이터 제공은 구현·활성화되지 않았으며 기본 로컬 처리만 사용합니다.
- 일부 성장 형태는 최종 아트가 아닌 검증용 번들 아트를 사용합니다.
