# 책먹는 몬스터 0.1.0-beta.2

두 번째 Windows 공개 베타입니다. 첫 베타의 기능과 로컬 데이터 보존 원칙을 유지하면서,
업데이트 확인과 공개 배포 경로의 무결성 방어를 강화했습니다.

## 이번 버전의 변경 사항

- 업데이트 manifest와 설치 파일 다운로드의 최종 리다이렉트 URL도 HTTPS인지 검증
- 비정상적인 manifest `Content-Length`를 안전하게 거부
- 이미 공개한 동일 버전의 설치 파일과 manifest를 덮어쓸 수 없도록 Release 불변 처리
- 동일 버전 manifest 변조와 업데이트 채널의 구버전 역행 차단
- 여러 Release가 동시에 실행될 때 업데이트 채널 발행을 직렬화
- Release 브랜치와 태그가 검증된 소스 커밋을 가리키는지 확인

## 설치와 데이터 보존

`BookEater-Setup.exe`를 기존 설치 위에 실행해도 프로그램 파일만 갱신합니다.
`%LOCALAPPDATA%\BookEater` 아래의 독서 기록 DB, 설정, 백업, 교정값과 성장 이력은
덮어쓰거나 삭제하지 않습니다. 필요한 스키마 변경은 설치 프로그램이 아니라 앱이 처음
실행될 때 사전 백업 후 트랜잭션으로 처리합니다.

## 베타에서 알고 있어야 할 점

- 아직 Authenticode 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.
- 온라인 도서 검색의 공개 카탈로그 서버는 아직 연결되지 않아 수동 등록으로 동작합니다.
- 분석 개선용 데이터 제공은 구현·활성화되지 않았으며 기본 로컬 처리만 사용합니다.
- 일부 성장 형태는 최종 아트가 아닌 검증용 번들 아트를 사용합니다.
